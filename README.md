# cangjie-skill

Installer and release home for skills distilled by **Cangjie** (仓颉) — the
content → executable-skill pipeline. Code and releases live here.

**Skill content (markdown) does not live on GitHub.** Files and information
stay on the Obsidian vault (`Knowledge/40-Templates/cangjie/`) and Notion.

## Install

```sh
./install.sh <skill-name> [profile]   # pulls SKILL.md from the vault via rclone
```

## Releases

Versioned bundles are cut when a distilled skill's `version` bumps — see Releases.
